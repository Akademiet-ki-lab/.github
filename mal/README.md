Én eller to setninger om hva prosjektet er, hvem det er for og hva det er laget med. Denne teksten vises på kortet under Publikasjoner i KI-lab-dashboardet.

![Skjermbilde](docs/skjermbilde.png)

## Slik bruker du det

Hvordan man spiller eller bruker appen.

## Slik kjører du det lokalt

```bash
npm install
npm run dev
```

## Laget av

Kallenavn eller GitHub-brukernavn.
